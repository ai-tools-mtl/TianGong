# 专利交底书附图设计原则

本技能管"图怎么设计才简洁好懂"——图序怎么规划、每张图画什么、标注怎么写。适用于规划交底书的附图结构与撰写「附图说明」章节。

注：本技能只提供设计原则，不涉及具体绘图工具的 XML 参数或渲染。用户使用何种工具（drawio/Visio/手绘）绘制由其自行决定。

## 核心原则（不可违背）

### 1. 黑白极简风格

专利附图不是彩色营销图。**全部使用黑白配色**，禁彩色填充、禁渐变色、禁彩色图标。

- ✅ 纯黑白，用线宽区分层级（关键单元粗线、普通单元细线）
- ✅ 虚线用于辅助数据流、可选流程、说明框
- ❌ 禁止灰色背景块、彩色填充、彩色图标

### 2. 总图先行，逐层深入

**第一张图必须是流程总览图**，让读者（专利代理人）5 秒内看懂全流程。后续图逐步展开细节。

图序规划模板：
```
图1  流程总览图    —— 阶段×实体矩阵，最高层视角
图2  系统架构框图  —— 实体 + 内部单元 + 数据流
图3  核心方法流程  —— 主权利要求对应的步骤流
图4+ 增强/变体流程 —— 各从属权利的独立流程
```

### 3. 中文标注，消除英文

所有实体名、步骤名、分支标签必须用中文。首次出现的英文缩写可附带在括号里（如"凭证代管方（Broker）"），后续仅用中文。

- ✅ "凭证所有者""凭证代管方""代理方"
- ❌ "Owner""Broker""Agent B"
- 公式符号（如 `rk`、`CT_O`）可保留原样，因其在正文中有定义

### 4. 一图一事，拒绝超长

单张图的纵向内容不超过 5~6 个主要步骤块。如果流程有 7+ 步骤，拆成两张图。

- 总图：阶段 × 实体矩阵，一屏看完
- 分图：每张 ≤ 6 个步骤块，含 1 个决策点

## 流程图元素规范

无论用何种工具绘制，流程图元素应遵循统一约定：

| 元件 | 约定 |
|------|------|
| 开始/结束 | 椭圆/圆角框 |
| 处理步骤 | 圆角矩形 |
| 判断/决策 | 菱形，含两条出口（通过/不通过） |
| 主流程箭头 | 实线 |
| 辅助/可选流 | 虚线 |
| 说明文字 | 灰色或小字号，与主内容区分 |

**决策菱形必须包含两条出口**：通过路径向下，拒绝/异常路径向侧面。

## 附图说明章节撰写

「附图说明」章节应简洁列出每张图的名称与作用，与正文章节呼应：

```
图1 为本发明所述方法的流程总览图；
图2 为本发明系统的架构框图；
图3 为本发明核心方法的步骤流程图；
图4 为本发明某增强实施例的流程图。
```

步骤编号须与正文「系统流程说明」的 S1-Sn 对应，便于代理人交叉定位。

## 检查清单

- [ ] 图1 是流程总览图（阶段×实体矩阵或等效高层视角）
- [ ] 全部黑白配色，无彩色填充
- [ ] 全部中文标注，英文缩写仅在首次给出
- [ ] 单张图纵向 ≤ 6 个主要步骤块
- [ ] 步骤编号与正文 S1-Sn 对应
- [ ] 箭头区分主/辅（实线/虚线）
- [ ] 决策节点包含两条出口（通过/不通过）
- [ ] 「附图说明」章节列全所有图，与正文呼应
